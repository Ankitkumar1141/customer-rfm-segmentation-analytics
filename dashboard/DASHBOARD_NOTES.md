## Data Source Connection

- Connect to `RetailAnalysis_Final.xlsx` (generated by `rfm-analysis/segmentation_and_churn.py`)
- Import mode (not DirectQuery) — dataset is static post-analysis

---

## DAX Measures

```dax
-- Total Revenue
Total Revenue = SUM(RetailAnalysis_Final[Revenue])

-- Total Customers
Total Customers = DISTINCTCOUNT(RetailAnalysis_Final[Customer_ID])

-- Churn Rate %
Churn Rate % =
DIVIDE(
    CALCULATE([Total Customers], RetailAnalysis_Final[Churned] = 1),
    [Total Customers],
    0
) * 100

-- Average Customer Value
Avg Customer Value =
DIVIDE([Total Revenue], [Total Customers], 0)

-- Revenue per Segment
Revenue by Segment =
CALCULATE(
    [Total Revenue],
    ALLEXCEPT(RetailAnalysis_Final, RetailAnalysis_Final[Segment])
)
```
